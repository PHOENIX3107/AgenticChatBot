# AgenticChatBot

A chatbot application built using LangGraph and Streamlit with support for OpenAI and Groq models.

### Features

- OpenAI and Groq integration
- LangGraph-based workflow
- Stateful chatbot architecture
- Streamlit user interface
- Modular project structure

### Tech Stack

- Python
- LangGraph
- LangChain
- Streamlit
- OpenAI
- Groq

### Run Locally

bash git clone https://github.com/PHOENIX3107/AgenticChatBot.git  cd AgenticChatBot  uv venv source .venv/bin/activate  uv sync  streamlit run app.py 

### Project Structure

text src/ ├── LLMs/ ├── UI/ ├── graph/ ├── nodes/ ├── state/ └── main.py
